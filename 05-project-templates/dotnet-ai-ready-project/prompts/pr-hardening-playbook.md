# Playbook: Підготовка PR До Злиття

## Мета
Підготувати pull request до безпечного злиття через посилення якості, тестів і документації.

## Вхідні дані
- Обсяг PR (feature/fix/refactor)
- Змінені файли
- Відомі зауваження з review

## Інструкції Для AI
1. Перевір коректність, регресії та порушення меж шарів.
2. Перевір узгодженість API і backward compatibility.
3. Перевір error handling, null safety та коректність async.
4. Перевір тести та визнач відсутні high-value тести.
5. Запропонуй лаконічні оновлення документації для decisions і tradeoffs.

## Формат Відповіді
1. Готовність до merge: Ready / Needs changes
2. Critical findings
3. Некритичні покращення
4. Прогалини в тестах
5. Запропоновані follow-up задачі

## Обмеження
- Пріоритет: зниження ризиків, а не стилістичні rewrite.
- Рекомендації мають бути практичними та в рамках scope.
