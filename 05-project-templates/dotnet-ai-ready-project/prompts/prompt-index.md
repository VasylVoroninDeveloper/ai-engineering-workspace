# Індекс Промптів

## Як користуватися
1. Вибери playbook під тип задачі.
2. Передай контекст: ціль, обмеження, шляхи файлів, ризики.
3. Вимагай структурований результат згідно output format у playbook.

## Каталог

### 1) Огляд архітектури
- Файл: prompts/architecture-review-playbook.md
- Коли використовувати: оцінка стану архітектури, пошук ризиків і надмірної складності.
- Результат: findings за критичністю + пріоритезовані зміни.

### 2) Безпечний рефакторинг
- Файл: prompts/safe-refactor-playbook.md
- Коли використовувати: спрощення коду без зміни поведінки.
- Результат: покроковий план + перевірка стабільності.

### 3) Підготовка PR до злиття
- Файл: prompts/pr-hardening-playbook.md
- Коли використовувати: фінальна перевірка перед merge.
- Результат: merge readiness + критичні ризики + тестові прогалини.

## Правила якості промптів
- Формулюй мету однією фразою.
- Додавай явні обмеження (без rewrite, без зміни контрактів).
- Вказуй expected output format.
- Для high-risk змін вимагай підтвердження перед реалізацією.
