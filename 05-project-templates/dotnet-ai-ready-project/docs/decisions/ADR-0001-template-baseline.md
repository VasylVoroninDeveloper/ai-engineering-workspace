# ADR-0001: Базові Конвенції Проекту

## Статус
Прийнято

## Дата
2026-05-17

## Контекст
Потрібно стандартизувати спосіб розробки .NET проектів з AI-асистентами, щоб зменшити хаос, дублювання рішень і ризик регресій.

## Рішення
1. Використовуємо template з фіксованими AI-правилами та workflow.
2. Розділяємо ролі документів:
- AGENTS.md: процес виконання задач.
- .github/copilot-instructions.md: технічні стандарти коду.
- .cursor/rules/*.mdc: локальні правила Cursor.
- prompts/*.md: task playbooks.
3. Для ризикових змін застосовуємо stop-and-ask політику.
4. Завершення задачі допускається лише після проходження quality gates.

## Наслідки
Позитивні:
- Передбачувана поведінка AI-асистента.
- Менше конфліктів інструкцій.
- Стабільніший code review процес.

Негативні:
- Вища дисципліна документації.
- Додатковий час на підтримку playbooks.

## Альтернативи
1. Тримати всі правила в одному файлі.
- Відхилено: важко підтримувати, високий ризик конфліктів.
2. Не використовувати формальні playbooks.
- Відхилено: результати асистента менш стабільні.

## Пов'язані артефакти
- AGENTS.md
- .github/copilot-instructions.md
- .cursor/rules/dotnet-architecture.mdc
- prompts/*
