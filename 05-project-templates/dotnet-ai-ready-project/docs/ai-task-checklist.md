# Чекліст AI-Задачі

Використовуй цей чекліст перед завершенням задачі.

## Scope Та Безпека
- Мета задачі чітко визначена.
- Визначені модулі/файли, які зачіпає зміна.
- High-risk зміни (DB/API/security) погоджені з користувачем.

## Реалізація
- Зміни інкрементальні та мінімальні.
- Межі поточної архітектури не порушені.
- Не додані зайві абстракції.

## Перевірка
- Build проходить.
- Релевантні тести проходять.
- Немає нових linter/analyzer помилок.

## Документація
- README оновлено, якщо змінилися поведінка або налаштування.
- docs/decisions оновлено для важливих архітектурних рішень.
- Tradeoffs і залишкові ризики задокументовані.

## Передача Результату
- Підсумок чіткий і лаконічний.
- Список змінених файлів наведений.
- Залишкові ризики та наступні кроки описані.
